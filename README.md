# Le Chambea

Aplicación móvil desarrollada con React Native y Expo para conectar usuarios con servicios y perfiles profesionales.

## Requisitos

- Node.js 18 o superior
- npm o yarn
- Expo CLI

## Instalación

```bash
npm install
npm start
```

## Scripts disponibles

- `npm start` - inicia la app en modo desarrollo
- `npm run android` - ejecuta la app en Android
- `npm run ios` - ejecuta la app en iOS
- `npm run web` - ejecuta la app en navegador
- `npm run build:web` - genera la versión web

## Estructura principal

- `src/features` - pantallas y funcionalidades por módulo
- `src/shared` - componentes reutilizables, utilidades y hooks
- `database` - scripts y migraciones de base de datos

## Nota

Este proyecto se usa como base para la experiencia de registro, chat, perfiles, favoritos y administración interna.
